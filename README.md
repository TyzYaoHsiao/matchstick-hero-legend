# 火柴勇者傳說Ⅱ

《火柴勇者傳說》的第二版：五位超級夥伴各自有一條轉職之路。舊版在 `../火柴勇者傳說`，兩個版本存檔分開。

劍與魔法風的放置打怪遊戲，由《軌道獵手》改編。主角是火柴勇者，五位超級夥伴會陸續加入。
直接雙擊 `index.html` 就能玩，不用架伺服器。

## 搬存檔（舊版 → 線上版）

存檔放在瀏覽器裡，換網址就讀不到。搬法：

1. **舊版**：把 `save-export.html` 放進舊版遊戲資料夾（跟 `index.html` 同一層），用當初玩的瀏覽器打開，按「複製存檔碼」。
   已經是新版的話，直接按左下角「匯出存檔」也可以。
2. **線上版**：按左下角「匯入存檔」，貼上存檔碼。

## 玩法

- **隊伍**：用金幣升級勇者、招募夥伴。每 25 級傷害翻倍。
- **轉職**：夥伴到 Lv25 / 50 / 100 / 200 / 400 會轉職，傷害再乘 1.5～3 倍，並解鎖新招式。

  | 夥伴 | 轉職之路（Lv1 → 25 → 50 → 100 → 200 → 400） | 招式重點 |
  |---|---|---|
  | 小牛先生 | E級獵人 → 暗殺者 → 影之術士 → 死靈統帥 → 影之支配者 → **暗影君王** | 影步瞬移連刺；「起來吧！」把打倒的怪化為影之軍團（最多 24 隻，每隻 +8% 傷害，首領必定收服），影兵會定時衝出去突擊；統治者的權柄把敵人舉起重摔；暗影之手；君王領域；暗影大爆發 |
  | 小狗先生 | 見習火法師 → 火焰術士 → 爆炎魔導師 → 煉獄大法師 → 焚天魔導 → **災厄炎帝** | 火球 → 火環 → 雙火球 → 煉獄火柱 → 火焰龍捲風 → 災厄隕石 |
  | 他誰 | 見習弓手 → 獵人 → 神射手 → 風暴遊俠 → 星隕箭聖 → **滅世箭神** | 一箭 → 雙連射 → 三目標 → 貫穿全場的疾風之箭 → 箭雨 → 滅世神箭 + 星辰墜落 |
  | 浩浩人 | 見習騎士 → 聖殿騎士 → 審判騎士 → 天罰聖騎 → 光耀聖騎 → **神罰騎士** | 聖光重擊 → 波及周圍 → 審判金雷連鎖 → 聖光柱 → 全場審判 → 神罰天雷 |
  | 漁夫先生 | 漁夫 → 釣魚達人 → 潮汐術士 → 怒濤領主 → 深海霸主 → **萬濤海神** | 魚叉 → 大波浪從腳下衝過全場（沖退敵人）→ 雙魚叉 → 地底水柱 → 漩渦（減速）→ 雙重海嘯巨浪 |

  暗影君王的設定參考《我獨自升級》主角的能力（影子萃取、君王領域、統治者的權柄、影子交換），但招式名稱、外型和數值都是這個遊戲自己的。召喚獸不會真的上場排隊，而是站在後方山坡當軍團，增加傷害並定時突擊，比較適合放置遊戲。
- **夥伴大招（地圖砲）**：每位夥伴腳下有能量條，約 30 秒充滿（每轉職一次快 2 秒）。滿了按 Q / W / E / R / T 或點戰場左上的頭像施放（還沒滿或場上沒怪時會提示原因），開「自動施法」會自己放。放之前有全畫面蓋板：斜線分割，左半邊放大頭像、右半邊招式名，播放時戰鬥暫停。傷害 = 夥伴傷害 ×（12 + 轉職階段 × 3），打全場。

  聖獸也會一起降臨。四聖獸：他誰召喚**青龍**、小狗先生召喚**鳳凰**、浩浩人召喚**白虎**、漁夫先生召喚**玄武**；另外小牛先生有專屬的**黑龍**，火柴勇者有瑞獸**麒麟**（勇者的大招，按 Y）。

  | 夥伴 | 大招 |
  |---|---|
  | 小牛先生 | 永夜軍臨・無盡深淵：天色變永夜、天空裂開深淵，幾十個影子士兵（含巨型兵）從地底爬出、從裂縫降下，列隊後全軍往右衝鋒踏過全場，最後深淵爆開 |
  | 小狗先生 | Explosion（鳳凰）：火鳳凰展開烈焰雙翼從左上方天空俯衝下來，砸在怪群中間，超大爆炸打全場 |
  | 他誰 | 萬箭齊發（青龍）：巨大青龍蜿蜒飛過全場，後面跟著漫天箭雨 |
  | 浩浩人 | EX．咖哩棒（Excalibur／白虎）：蓄力時白虎在背後浮現；光粒子聚到劍上化成沖天光柱，往前揮下變成橫掃全場的巨大金色光束，白虎跟著光束一起撲出去 |
  | 火柴勇者 | 麒麟・天威烈焰（瑞獸麒麟）：金鱗、龍頭雙角、火焰鬃毛的麒麟踏著火雲從勇者身後奔出，一路燒過全場，最後在怪群中間踏出火柱 |
| 小牛先生（君王聖獸，不屬於四聖獸） | 黑龍（原創設計：黑色金屬鱗甲、深紅眼睛、紅色翼脈的蝙蝠式大翼）：放「永夜軍臨・無盡深淵」時，黑龍從天空的深淵裂縫飛出，拍著翅膀飛過影子大軍上空，一路往地面噴紫黑色龍息 |
| 漁夫先生 | 萬濤・怒海狂瀾（玄武，站在巨浪的浪頭上）：漩渦拉住全場，兩道巨浪接連衝過去 |
- **小怪**：17 種，每個區域出現的不一樣（設定在 `js/config.js` 的 `zoneMonsters`）：草原有史萊姆、哥布林、野狼、毒蘑菇；森林有獸人戰士、巨蜘蛛；墓地有骷髏兵、怨靈；火山有火蜥蜴、狂戰矮人、岩石魔像；雪原有冰精靈、雪怪；魔王城有黑暗騎士、石像鬼。
- **首領**：每種怪物都有專屬首領造型（史萊姆王、哥布林酋長…），另外每個區域有一隻**區域霸主**，固定在區域最後一關（每 5 關）以**章節首領**身分登場：翠綠草原「巨木樹人」、幽暗森林「森林巨魔」、骷髏墓地「死靈法師」、熔岩火山「熔岩炎魔」、冰霜雪原「冰霜巨人」、魔王城「黑暗魔王」。
- **難度曲線**：前 75 關每關血量 ×1.2，之後 50 關內慢慢降到每關 ×1.06（五位夥伴都招募後隊伍每關大約只能變強 5%，原本一直 ×1.2 會在 150 關後撞牆）。每區小怪的平均血量都調成一樣，換區域不會忽難忽易；一般首領不管抽到哪種怪都一樣硬；章節首領血量 ×1.3、限時 60 秒（一般首領 45 秒），需要的 DPS 跟一般首領差不多。數值在 `js/config.js` 的 `hpKnee`、`hpTaper`、`hpGrowthLate`、`chapterBossMul`、`chapterBossTime`。
  改數值後可以跑 `node tools/balance_sim.js 400`（`EVERY=10` 每 10 關印一行、`SEED=2` 換亂數），會模擬一個自動升級、抽卡、學院研究的玩家，列出每關大概要打多久。
- **章節演出**：每個區域是一章。進入新章節會出現章節標題；第一次遇到章節首領會先對話；打倒後出現「第 N 章 完」。台詞都在 `js/config.js` 的 `chapters`，點戰場可以跳過。
- **裝備背包**：60 格，滿了新裝備會自動賣掉。
- **職業道具**：每位夥伴手上拿著職業武器（法杖、雙匕首、弓、聖劍＋盾、三叉戟），轉職越高光越強。
- **夥伴施法動作**：夥伴每次攻擊都會先蓄力（舉手聚光、腳下法陣），出手那一刻才放出招式；他誰會往前衝刺並留下殘影。動作圖在 `超級夥伴/sprites.js` 的 charge / cast 姿勢。
- **鬥氣**：勇者到 Lv10 / 25 / 50 / 100 / 200 / 350 / 500 會「鬥氣突破」，傷害倍增，身上的鬥氣顏色、光環、腳下符文陣也會跟著升級。
- **夥伴光環**：轉職後身上有職業顏色的鬥氣光暈和火焰粒子，第 3 階起腳下有旋轉符文陣。
- **技能**：打首領拿魔晶，去「技能」分頁學。數字鍵 1～6 或點戰場左下技能列施放，也可以開「自動施法」。技能 Lv10 會覺醒，特效和傷害加強。
- **裝備**：首領一定掉裝備，小怪偶爾掉。分武器、頭盔、鎧甲、披風、戒指五個部位，六種稀有度（普通→神話）。穿上後火柴人的外觀會跟著變（劍的顏色長度、頭盔、皇冠、披風、鎧甲）。可以用金幣強化到 +15。
- **學院**：用魔晶研究永久加成。
- **收成**：冒險者公會（金幣）和魔晶礦脈照真實時間累積，滿倉就停，記得回來收。
- **裝備召喚**：打倒首領拿召喚券（一般首領 5 張、章節首領 10 張），在「裝備」分頁抽裝備（×1 或 ×10），有召喚陣蓄力、翻卡動畫，點畫面可以跳過。沒有普通品質，裝備等級等於歷來最高關卡。機率和張數在 `js/config.js` 的 `gacha`，沒有保底。
- **特殊事件（超級女人）**：打一般關卡時第一次大約 1 分半，之後每 4～7 分鐘發生一次。某位夥伴被她叫走（頭上冒圖示、暫時不攻擊也不放大招），她變成特殊首領登場：「電話來囉」漁夫先生 ↔ 齜牙影鬼、「開車載我」小牛先生 ↔ 英俊甲蟲、「幫我付錢」小狗先生 ↔ 多汁荔枝、「我要吃牛排」火柴勇者 ↔ 厲害蚊子（夥伴要先招募；勇者被叫走時不揮劍，點擊和技能照常）。她的血量會照「留下來的隊伍」實際打得多快來調整（開打第 6、16 秒各校正一次），所以不管叫走的是主力還是小角色，都是一場大約 25～40 秒的仗，一定比同一隊打一般首領久（一般首領通常 5～30 秒），但 60 秒內打得完。60 秒內打倒她：夥伴回來，拿到 15 張召喚券（只有召喚券，沒有魔晶和裝備）；時間到她就走掉，關卡照常繼續、不會被打斷進度。台詞、獎勵、頻率都在 `js/config.js` 的 `specialEvent`、`specialBosses`；造型從「超級女人」資料夾輸出（`python tools/export_game.py`）。測試：網址加 `?event=w_ghost`（或 `w_beetle`、`w_lychee`、`w_mosquito`），幾秒後就會發生。
- **圖鑑**：左下角「圖鑑」按鈕，分成角色、章節首領、首領、特殊首領四頁，看每個角色和首領的圖和名稱。按「關閉」、點外面或按 Esc 關掉。

## 效能

- 網址加 `?prof` 會記錄畫面每一段的耗時（`G.prof`），找掉幀的原因用。
- 像素特效（pixelfx）是最吃效能的部分：只清上一格畫過的範圍、同時最多 50 個特效，特效多的時候會省略純裝飾的火花和煙霧。
- 聖獸圖片（`img/beasts`）和怪物圖片（`img/monsters`）是縮小過的版本，原圖在 `../素材大集合`。
- 連續 3 秒掉到約 38 FPS 以下會自動切低畫質（關光暈、粒子減半、降解析度）。

## 檔案分工

| 檔案 | 負責什麼 |
|---|---|
| `js/config.js` | 所有數值：怪物、夥伴、鬥氣階段、技能、裝備、學院 |
| `js/state.js` | 存檔與公式（傷害、價格、裝備屬性、離線收益） |
| `js/battle.js` | 戰鬥：生怪、勇者攻擊、技能、鬥氣突破、轉職、掉寶、首領 |
| `js/classes.js` | 五位夥伴的職業：每一階出手時放什麼招、影之軍團 |
| `js/pfx.js` | 把 pixelfx 像素特效疊到戰場上 |
| `js/sprites.js` | 怪物和裝備圖示的像素圖 |
| `js/render.js` | 畫面：背景、火柴勇者（含裝備與鬥氣）、夥伴、怪物 |
| `js/ui.js` | 左右面板、技能列、提示訊息 |
| `js/main.js` | 啟動、縮放、遊戲迴圈、自動存檔 |
| `js/lib/pixelfx.js` | 打包好的 pixelfx 特效（46 種） |
| `js/lib/partners.js` | 五位夥伴的像素圖，複製自 `../超級夥伴/sprites.js` |

改了 `超級夥伴/sprites.js` 之後，把它再複製一份到 `js/lib/partners.js` 就會更新遊戲裡的夥伴。

存檔在瀏覽器的 localStorage（和《軌道獵手》分開存），每 5 秒自動存一次。
